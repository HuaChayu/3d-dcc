# model — 大模型层（保留位）

本目录专用于放置**大模型（AI / ML）相关代码**，与业务数据模型严格区分：

- 模型权重加载与配置（如 MLX / Core ML 的权重路径、量化参数）
- 推理管线（文本编码、去噪采样、解码出图/出视频）
- 模型封装与协议适配（如统一 `推理后端` 协议 + 各模型实现）
- 预处理 / 后处理算子

建议内部按模型族再分层，例如：

```
model/
├── 基础/       # 通用算子、张量工具、内存/缓存策略
├── 网络/       # 主干网络模块
├── 模块/       # 各模型专属可复用模块
├── 组装/       # 端到端 pipeline 组装与调用
└── 适配/       # 对外协议实现（推理后端、能力声明）
```

> 注意：`data/` 存放的是业务数据结构（材质、节点、场景、持久化），不要与本目录混放。
